## TC-3-BOUND-01
- **Title:** [Boundary] New password at the minimum length is accepted and one character below is rejected — min length
- **Preconditions:**
  - User opened a valid reset link from the email sent to user@test.com
  - User is on the reset password form
  - The minimum length is defined in the system security requirements as N characters
- **Steps:**
  1. Type a compliant password of exactly N-1 characters, for example "Ab#1" padded to N-1 characters, into the New Password field
  2. Submit the reset password form
  3. Type a compliant password of exactly N characters into the New Password field
  4. Submit the reset password form
- **Expected Result:** The N-1 character password is rejected with a requirements error. The N character password is accepted and a confirmation message is shown.
  PASS — N-1 characters is rejected and N characters is accepted.
- **Test Data:** password lengths: N-1 and N (N = configured minimum length), including one special character
- **Type:** Boundary
