## TC-3-BOUND-01
- **Title:** [Boundary] New password exactly at the minimum length is accepted and one character below is rejected
- **Preconditions:**
  - User opened a valid reset link and is on the reset password form
  - Minimum password length is known from the security policy (assumed 8 characters for this test)
- **Steps:**
  1. Type "Abcd#12" (7 characters) into the New Password field
  2. Type "Abcd#12" into the Confirm Password field
  3. Click the submit button on the reset form
  4. Clear both fields and type "Abcd#123" (8 characters) into the New Password and Confirm Password fields
  5. Click the submit button on the reset form
- **Expected Result:** The 7-character password is rejected with a minimum length error; the 8-character password is accepted and the confirmation message is shown.
  PASS — 7 characters rejected, 8 characters accepted with confirmation message.
- **Test Data:** too short: Abcd#12, minimum length: Abcd#123, assumed minimum: 8
- **Type:** Boundary
